ER · stock module

stock 데이터 모델

주식 Gap & Pullback 봇(한국투자증권 API)의 6개 테이블입니다. JPA 엔티티 기준이며 테이블은 Hibernate ddl-auto: update 가 만듭니다. JPA 연관관계가 없어 DB FK 도 없습니다.

Fig. 1

모니터링 · 포지션 · 주문

stock_monitoring 은 09:20 스크리닝에서 선정된 종목만, 종목·거래일마다 한 행(UQ)으로 저장됩니다. 이 행의 state 가 눌림목 상태머신을 따라 바뀝니다. 포지션은 stock_id 로, 주문은 position_id 로 FK 없이 가리킵니다. 신호와 진입 시도는 id 를 갖지 않고 stock_code 와 날짜로만 대응합니다(점선). stock_candles 는 저장소 어댑터 외에 쓰는 코드가 없는 비활성 스캐폴딩입니다.

Database

DB 가 보장하는 것

  • FK 없음 — stock_id·position_id 는 평범한 bigint
  • UQ — stock_monitoring (stock_code, trading_date), stock_candles (stock_code, candle_datetime, interval_type)
  • stock_trades.order_id 는 인덱스만 있고 UQ 아님

Application

코드가 보장하는 것

  • 선정 종목마다 모니터링 행과 GAP_DETECTED 신호를 함께 저장 — ScreeningService
  • 진입 시 포지션에 stock_id, 주문에 position_id 연결 — StockPositionService
  • 진입 판정마다 통과·거절 사유를 stock_entry_attempts 에 기록 — 일일 실적 리포트가 거절 사유 분포로 집계

Retention

보관

  • deleteBy…Before 계열 메서드는 저장소에 정의만 있고 호출처 없음

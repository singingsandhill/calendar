주의: ① KRW 보유는 수익·낙폭이 모두 0 이라 "위험조정으로 이긴다" 는 총수익 > 0 과 같아진다 — 이긴 설정도 MDD 가 수십 % 다. ② 일봉 한 기간(같은 기간 단순 보유 MDD 87.2%)의 결과이고 18개 중 고른 값이라 과최적화 위험이 크다. ③ 하루 한 번 시가 체결·신호 매매와의 상호작용 없음 — 운영 엔진(분 단위, 쿨다운 8시간)과 다르다. ④ 레짐 설정(`trading.regime.*`)은 신호 매수 필터와 공유하고, 필터와 리밸런싱을 함께 켜는 조합은 제안하지 않는다(4-D).

KRW 보유 대비 = 총수익 > 0, 단순 보유 대비 = 총수익÷MDD 가 더 큼(단순 보유가 손실이면 음수끼리 비교).

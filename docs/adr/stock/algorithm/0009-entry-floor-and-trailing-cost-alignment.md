# ADR-0009 (stock/algorithm): 진입 풀백 하한·트레일링 폭을 비용 게이트와 정합

| 항목 | 값 |
|---|---|
| 상태 | Accepted — 2026-08-03 에 time-decay 최소수익 곡선의 종점이 상수(09:10/15:15)에서 `trading.trading-loop-start`/`exit.final-exit-time` 유도로 바뀌어 TP 순이익 게이트 임계가 달라졌다: 11:20 기준 0.358% → 0(구간 종점), 10:20 기준 0.423% → 0.300%. 장 후반 게이트가 실제로 완화된다(원 설계 의도) |
| 날짜 | 2026-07-25 |
| 도메인 | stock |
| 관심사 | 알고리즘 / 진입·청산 |
| 관련 | [0007 출구 재보정](0007-exit-structure-recalibration.md), [0008 선정·비용 모델](0008-screening-selection-and-cost-model.md), 수익성 검사 2026-07-25 |

## Context — 무엇이 문제였나

0008 에서 익절 게이트가 실효 청산 비용(왕복 수수료·세금 0.23% + 슬리피지 0.2% =
0.43%)과 시간감쇠 최소수익(09:20 실질 ~0.49%)을 net 기준으로 차단하게 됐다. 그런데
진입·트레일링 파라미터는 이 게이트와 정합되지 않았다.

1. **얕은 풀백 진입은 구조적으로 익절 불가.** 진입 허용 풀백 1.0~5.0% 중 1.0~1.3%
   구간은 TP2(전고점 회복) 기대 이득이 게이트를 못 넘는다. 풀백 깊이 d 에서 TP2 총이득
   ≈ `1/((1-d)×1.002) − 1`: d=1.0% → 0.81% 총이득, 비용 0.43% 차감 시 0.38% —
   09:20 게이트(0.489%) 미달. 이 진입은 손절(−1.2%)·본전·11:20 강제청산만 남는다.
   트레일링도 부분익절이 선행해야 활성화되므로 러너 경로도 없다.
2. **트레일링 3.8% 는 사실상 본전 스탑.** 스탑 = `max(고점 × (1−3.8%), 손익분기)` 인데
   고점이 진입가 × 1.0043/0.962 ≈ **+4.4%** 를 넘어야 트레일이 손익분기보다 위로
   올라간다. TP1(+5%) 직전까지 러너 40% 의 기대 기여가 0 에 수렴한다.

승자 기대치 ≈ +0.84%(TP2 60% + 러너 0%) vs 패자 ≈ −1.4~−1.6% → 손익분기 승률
≈ 62~64% 로, 0007 재보정 의도(~50%)보다 크게 불리했다.

## Decision — 무엇을 골랐나

- **`entry.pullback-min-percent` 1.0 → 1.5.** d=1.5% 면 TP2 총이득 1.32%, 비용 차감
  후 0.89% — 게이트(0.49%)를 여유 있게 넘는다. 게이트를 넘을 수 없는 진입은 아예
  받지 않는다.
- **`risk.trailing-stop-percent` 3.8 → 2.0.** 트레일이 손익분기 위로 올라오는 지점이
  진입가 +4.4% → **+2.5%** (`1.0043/0.98`) 로 내려와, TP2 이후 러너가 실제로 이익을
  잠근다. 손익분기 하한(0007)은 유지 — 활성화 직후 최악의 경우도 본전.
- **Java 기본값을 yaml 운영값과 정합** (Entry·Exit·Risk 클래스). yaml 키 누락 시 구식
  값으로 조용히 회귀하는 사고 방지 — 코인 감사 P1-9 와 동일 원칙.

## Rationale — 왜 이 선택인가

| 대안 | 기각 이유 |
|---|---|
| 게이트(시간감쇠 최소수익)를 낮춤 | 비용 미달 익절을 허용 — 명목 이익·실질 손실 (0008 취지 역행) |
| 진입 하한 유지 + 얕은 풀백만 별도 TP | 출구 구조 분기 — 복잡도 대비 이득 없음 |
| 트레일 폭을 더 좁게 (예: 1.0%) | 5초 폴링 잡음에 러너가 즉시 털림 — 활성 직후 노이즈 스탑아웃 |
| **(선택) 진입 하한 상향 + 트레일 2.0%** | 게이트와 진입·러너 기하를 정합 — 파라미터 2개 변경으로 구조 해소 |

트레이드오프: 진입 하한 상향은 표본을 줄인다 (0008 이 갭 floor 를 0.5% 로 유지한
것과 반대 방향). 단 여기서 버리는 표본은 **이길 수 없는 표본**이라 실측 신호를
오염시키지 않고 오히려 정화한다.

## Consequences — 영향

- **긍정:** 모든 진입이 이론상 익절 도달 가능. 러너가 +2.5% 부터 이익을 잠가
  손익분기 승률 추정이 ~62–64% → ~50%대 로 복귀 (0007 의도 회복).
- **부정/주의:** 진입 빈도 감소 (PAPER 실측 표본 축적이 느려짐). 두 값 모두 실측
  없는 이론 보정 — **P2-5 PAPER 2~4주 실측으로 검증 후 확정**해야 한다.
- 수치는 `StockRiskServiceSlippageGateTest` / `StockCostModelTest` 의 비용 모델을
  전제로 한다. 비용 상수 변경 시 이 ADR 의 기하도 재검토.

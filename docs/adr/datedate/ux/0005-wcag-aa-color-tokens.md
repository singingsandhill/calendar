# ADR-0005: 강조·위험·비활성 날짜 색을 WCAG AA 대비 기준으로 — `#1f6fa8` / `#c0392b` / `--text-light`

| 항목 | 값 |
|---|---|
| 상태 | Accepted |
| 날짜 | 2026-10-21 |
| 도메인 | datedate |
| 관심사 | UX / 접근성 |
| 관련 커밋 | `docs/guides/git-commit.md` Commit 208 (코드·가용 배경 위 글자색 후속 포함), 209 (이 ADR) |
| 관련 이슈 | 모바일 점검(2026-10-21, 375·320px 실측) |

## Context — 무엇이 문제였나

- `style.css :root` 의 `--primary-color #3498db` 는 흰 배경 3.15:1, 본문 배경 `#f5f5f5` 2.89:1 이다. 테두리 버튼 글자·"N표"·
  흰 글자를 올린 꽉 찬 버튼(+ 일정 만들기, 저장)이 모두 일반 글자 AA(4.5:1)에 못 미친다.
- `--danger-color #e74c3c` 위 흰 글자("삭제") 3.82:1, 달력 이전·다음 달 날짜 `#999` 는 셀 배경 `#f8f9fa` 위 2.70:1.
- 강조색 작은 글자가 **회색 배경 위에도** 쓰인다(브라우저 스캔): 일정 페이지 헤더 "링크 복사"·"도움말 보기"·"+ 설명 추가"(14~16px,
  본문 배경), 대시보드 "이번 달", 홈 "랜덤 생성", 시나리오 카드 "자세히 보기", 장소·메뉴 항목의 "N표"(`#f5f5f5` 카드).

## Decision — 무엇을 골랐나

텍스트에 쓰는 색 토큰은 **WCAG 2.1 AA**(일반 글자 4.5:1, 큰 글자 3:1)를 흰 배경과 `#f5f5f5` 양쪽에서 통과해야 한다.

| 토큰 | 이전 → 이후 | 흰 배경 | `#f5f5f5` | 비고 |
|---|---|---|---|---|
| `--primary-color` | `#3498db` → `#1f6fa8` | 5.39 | 4.94 | 흰 글자를 올려도 5.39 |
| `--primary-dark` (hover) | `#2980b9` → `#185a88` | 7.35 | 6.74 | 새 기본색보다 진해야 hover 가 옅어지지 않는다 |
| `--danger-color` | `#e74c3c` → `#c0392b` | 5.44 (흰 글자) | 4.99 | `.btn-danger:hover` 는 `#a93226` |
| 이전·다음 달 날짜 | `#999` → `var(--text-light)` (#666) | 5.74 | — | 실제 셀 배경 `#f8f9fa` 위 5.45 |

- `style.css` 안 datedate 페이지가 쓰는 `#3498db` 계열 하드코딩은 변수로 바꾼다 — 포커스 링·시작 CTA 그림자는
  `color-mix(in srgb, var(--primary-color) N%, transparent)`, 인사이트 달력 아이콘 그라데이션은 `--primary-color → --primary-dark`.

## Rationale — 왜 이 선택인가

| 대안 | 대비 | 기각 이유 |
|---|---|---|
| `#3498db` 유지 | 3.15 / 2.89 | 일반 글자 AA 미달 |
| `#2477b3` (가장 덜 어두운 후보) | 4.81 / 4.41 | `#f5f5f5` 위 작은 글자가 실재해 4.41 은 미달 — 큰 글자만 통과 |
| **`#1f6fa8`** | 5.39 / 4.94 | 두 배경 모두 통과하는 가장 밝은 쪽 후보 |
| 다른 달 날짜 `#767676` | 흰 4.54, `#f8f9fa` 4.31 | 흰 배경 기준 값이라 실제 셀 배경에서 미달 — 기존 토큰 `--text-light` 를 재사용 |

## Consequences — 영향

- **긍정:** 강조색 글자·꽉 찬 버튼·삭제 버튼·비활성 날짜가 AA 를 통과한다(브라우저 실측, 위 표).
- **부정:** 브랜드 파랑이 한 톤 어두워진다. 로고·통계 숫자·카드 헤더 등 큰 글자·배경 용도도 함께 바뀐다(토큰 단일화).
- **범위:** `style.css` 는 러너 페이지도 `fragments/head` 로 로드하지만 러너 템플릿은 `runners-*` 클래스를 써서
  `button:focus-visible` 포커스 링 색만 바뀐다. 트레이딩·주식 페이지는 이 파일을 로드하지 않는다.
- **가용 배경 위 글자:** 히트맵 초록(heat-2~5)과 참여자 색은 의미 색이라 배경은 그대로 두고 **글자색만** 맞춘다.
  heat-5plus 의 흰 글자는 그 배경 위 2.34:1 이라 본문색 `--text-color`(5.39), 가용 배경(solo·heat-2~4) 위 다른 달 날짜도
  `--text-light` 가 heat-3·4(3.99·3.21)와 참여자 색 틴트 10색 중 6색(4.31~4.46)에서 미달이라 본문색(7.07~10.33). 빈 다른 달 셀만 회색.
  ux/0001 은 명도 단계와 'AA 충족 색' 을 정했을 뿐 흰 글자를 결정하지 않았다 — 이 정렬은 그 AA 원칙의 적용이다.
- **바꾸지 않은 것:** `theme-color` 메타·웹 매니페스트의 `#3498db` 는 브라우저 UI 색(글자 대비 무관)이라 그대로.
- **후속:** `/guide` 단계 스크린샷(`static/image/guide/{ko,en}/step*.webp`)이 옛 색이라 재촬영 대상이다.
- 새 색을 토큰에 넣을 때는 흰 배경과 `#f5f5f5` 대비를 함께 재측정한다.

# ADR-0008: 미지 콘텐츠 슬러그는 홈 리다이렉트가 아니라 HTTP 404

| 항목 | 값 |
|---|---|
| 상태 | Accepted |
| 날짜 | 2026-08-18 |
| 도메인 | datedate |
| 관심사 | SEO / 에러 처리 |
| 관련 커밋 | (AdSense 3차 통지 대응 배치) |
| 관련 이슈 | [진단 2026-08-17](../../../audit/adsense-low-value-content-diagnosis-2026-08-17.md) |

## Context — 무엇이 문제였나

`GET /use-cases/{slug}` 는 `UseCaseSlugs.ALL` 미포함 슬러그를 `localeLinks.redirect("/")`
로 홈에 302 리다이렉트했다. AdSense "낮은 가치 콘텐츠" 3차 통지(2026-08-17) 진단에서
부수 신호로 확정:

1. **소프트 404** — 존재하지 않는 콘텐츠 URL 공간 전체가 200(홈)으로 수렴. 크롤러에는
   "무한 URL 이 전부 같은 페이지" 라는 품질 신호 오염이자, GSC 에서 soft-404 로 분류될
   수 있는 패턴.
2. **ADR-0004 와 비대칭** — owner 경로는 이미 GET 무변형 + 정직한 404 로 전환됐는데,
   콘텐츠 슬러그 경로에만 같은 패턴이 남아 있었다.

## Decision — 무엇을 골랐나

- 미지 슬러그는 `UseCaseNotFoundException` (`BusinessException`, 404) 을 던진다 →
  `MvcExceptionHandler` 가 `error/4xx` 를 렌더링.
- 이후 추가되는 콘텐츠 슬러그 계열(`/guides/{slug}` 등)도 동일 규칙을 따른다.

## Rationale — 왜 이 선택인가

| 대안 | 기각 이유 |
|---|---|
| 현행 유지 (302→홈) | 소프트 404 잔존 — 진단 §3-3 부수 신호 |
| 404 + 빈 상태 커스텀 뷰 (ADR-0004 방식) | owner 페이지는 "내 ID 로 시작" 온보딩 흐름이 있어 빈 대시보드가 UX 로 정당화되지만, 콘텐츠 슬러그는 오타/삭제 링크뿐이라 표준 에러 페이지가 정확하다 |
| **(선택) 404 + error/4xx** | 크롤러에 표준 신호, 기존 2-레이어 예외 처리 재사용, 추가 템플릿 불요 |

## Consequences — 영향

- **긍정:** 콘텐츠 URL 공간의 경계가 크롤러에 정직해진다. 슬러그 삭제 시에도 안전한
  기본 동작(404)이 된다.
- **부정/트레이드오프:** 과거 302 를 캐시한 클라이언트는 만료까지 홈으로 이동. 무시 가능.
- **회귀 가드:** `UseCaseLocaleRenderingTest.unknownSlug404` — 302 로 되돌아가면 RED.
